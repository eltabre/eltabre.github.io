Most editor themes are invented palettes. These aren't — each variant takes its
colours from somewhere I've actually walked, which constrains the choices in a
useful way. A palette pulled from real terrain already has a working
relationship between its colours, because light on a hillside does not produce
arbitrary combinations.

The practical test for a theme is long sessions rather than screenshots. Enough
contrast to separate syntax at a glance, not so much that it wears you out after
an hour.

Published on the VS Code marketplace; the demo link previews the Pine variant
against real code.
